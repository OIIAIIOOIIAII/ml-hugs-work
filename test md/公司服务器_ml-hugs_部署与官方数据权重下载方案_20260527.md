# 公司服务器 ml-hugs 部署与官方数据/权重下载方案

本文档用于在公司云服务器上重新配置当前 `ml-hugs` 项目，使其能够运行官方 NeuMan 数据、官方 HUGS 预训练权重，以及当前私有仓库中的代码改动。

重要边界：

- 不拷贝当前服务器 `output/` 下的训练结果。
- 不拷贝当前服务器 `data/human3r_hugs/`、`data/neuman/dataset/lab/human3r/`、`depthpro_*` 等自己生成的实验数据。
- 官方 NeuMan 原始数据和官方 HUGS pretrained weights 直接从 Apple 官方链接下载。
- SMPL 模型受许可限制，需要人工从 SMPL 官网下载后放入指定目录。

## 0. 目标目录约定

以下命令假设公司服务器项目路径为：

```bash
/workspace/ml-hugs
```

如果实际路径不同，请把文档中的 `/workspace/ml-hugs` 替换成实际路径。

如果公司服务器有 NAS，建议把项目代码放在本地高速盘，把大数据放在 NAS。例如：

```bash
/workspace/ml-hugs                 # Git 代码目录，本地盘优先
/mnt/nas/ml-hugs-data/data          # 可选：官方 data 目录
/mnt/nas/ml-hugs-data/output        # 可选：官方 pretrained_models 目录
```

如果没有 NAS，直接把 `data/` 和 `output/pretrained_models/` 放在项目目录下即可。

## 1. 系统前置检查

建议环境：

- Ubuntu 22.04 或接近版本
- NVIDIA GPU
- CUDA driver 支持 CUDA 11.7 对应的 PyTorch wheel
- 已安装 `git`、`wget`、`unzip`、`conda`

检查命令：

```bash
nvidia-smi
git --version
wget --version
unzip -v | head
conda --version
```

如果缺少系统工具，在 Ubuntu 上可执行：

```bash
sudo apt-get update
sudo apt-get install -y git wget unzip build-essential
```

## 2. 拉取当前私有代码仓库

```bash
cd /workspace
git clone git@github.com:OIIAIIOOIIAII/ml-hugs-work.git ml-hugs
cd /workspace/ml-hugs
git submodule update --init --recursive
```

如果公司服务器没有配置 GitHub SSH key，可以先用 HTTPS 克隆：

```bash
git clone https://github.com/OIIAIIOOIIAII/ml-hugs-work.git ml-hugs
```

如果仓库是 private，HTTPS 方式需要 GitHub token。

拉取后确认远端：

```bash
git remote -v
git status --short --branch
```

期望看到当前分支跟踪 `origin/main`。

## 3. 创建 Python/Conda 环境

项目自带环境脚本：

```bash
cd /workspace/ml-hugs
source scripts/conda_setup.sh
```

该脚本会创建名为 `hugs` 的 conda 环境，并安装：

- Python 3.8
- PyTorch 1.13.1
- torchvision 0.14.1
- torchaudio 0.13.1
- pytorch-cuda 11.7
- pytorch3d
- diff-gaussian-rasterization 子模块
- simple-knn 子模块
- `requirements.txt` 中的依赖
- chumpy

之后每次进入项目运行：

```bash
conda activate hugs
cd /workspace/ml-hugs
```

如果 `source scripts/conda_setup.sh` 中途失败，优先检查：

```bash
conda activate hugs
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
python -c "import pytorch3d; print('pytorch3d ok')"
python -c "import diff_gaussian_rasterization; print('diff gaussian ok')"
python -c "import simple_knn; print('simple knn ok')"
```

如果 `diff_gaussian_rasterization` 或 `simple_knn` 编译失败，通常是 CUDA toolkit、gcc 或 PyTorch CUDA 版本不匹配，需要先解决编译环境。

## 4. 下载官方 NeuMan data 和官方 pretrained weights

官方 HUGS README 给出的链接：

- NeuMan data: `https://docs-assets.developer.apple.com/ml-research/models/hugs/neuman_data.zip`
- HUGS pretrained models: `https://docs-assets.developer.apple.com/ml-research/models/hugs/hugs_pretrained_models.zip`

推荐直接使用项目脚本：

```bash
cd /workspace/ml-hugs
conda activate hugs
bash scripts/prepare_data_models.sh
```

该脚本等价于：

```bash
wget https://docs-assets.developer.apple.com/ml-research/models/hugs/neuman_data.zip
wget https://docs-assets.developer.apple.com/ml-research/models/hugs/hugs_pretrained_models.zip
unzip -qq neuman_data.zip
unzip -qq hugs_pretrained_models.zip
rm neuman_data.zip hugs_pretrained_models.zip
```

下载完成后，期望目录结构包括：

```text
data/neuman/dataset/bike
data/neuman/dataset/citron
data/neuman/dataset/jogging
data/neuman/dataset/lab
data/neuman/dataset/parkinglot
data/neuman/dataset/seattle
output/pretrained_models/bike
output/pretrained_models/citron
output/pretrained_models/jogging
output/pretrained_models/lab
output/pretrained_models/parkinglot
output/pretrained_models/seattle
```

可以检查大小：

```bash
du -h -d 2 data/neuman output/pretrained_models
```

参考当前服务器大小：

```text
data/neuman                  约 6.9G
output/pretrained_models     约 9.4G
```

## 5. 如果 data/weights 要放到 NAS

如果公司服务器挂载了 NAS，例如 `/mnt/nas`，建议把官方下载得到的 `data/` 和 `output/pretrained_models/` 移到 NAS，再在项目目录建软链接。

示例：

```bash
mkdir -p /mnt/nas/ml-hugs-assets
cd /workspace/ml-hugs

mv data /mnt/nas/ml-hugs-assets/data
mkdir -p /mnt/nas/ml-hugs-assets/output
mv output/pretrained_models /mnt/nas/ml-hugs-assets/output/pretrained_models

ln -s /mnt/nas/ml-hugs-assets/data data
mkdir -p output
ln -s /mnt/nas/ml-hugs-assets/output/pretrained_models output/pretrained_models
```

检查：

```bash
ls -l data
ls -l output/pretrained_models
```

注意：训练输出可以继续写到项目本地 `output/`，不要把所有训练结果默认写入 NAS，除非公司平台要求这么做。

## 6. 准备 SMPL 模型

SMPL 模型不能从 HUGS GitHub 或 Apple 下载包直接获得，需要按许可证从 SMPL 官网下载。

操作步骤：

1. 注册并登录 SMPL 官网：`https://smpl.is.tue.mpg.de/index.html`
2. 下载 SMPL v1.1.0。
3. 下载 SMPL UV obj 文件。
4. 解压后找到 neutral 模型文件，并重命名：

```text
basicModel_neutral_lbs_10_207_0_v1.0.0.pkl -> SMPL_NEUTRAL.pkl
```

5. 放到项目目录：

```bash
mkdir -p /workspace/ml-hugs/data/smpl
```

最终结构必须是：

```text
/workspace/ml-hugs/data/smpl/SMPL_NEUTRAL.pkl
/workspace/ml-hugs/data/smpl/smpl_uv.obj
```

检查命令：

```bash
ls -lh /workspace/ml-hugs/data/smpl/SMPL_NEUTRAL.pkl
ls -lh /workspace/ml-hugs/data/smpl/smpl_uv.obj
```

如果当前服务器允许传少量文件，也可以只传 `data/smpl/`。这部分约 237M，比传完整 data 小很多。

## 10. 官方训练 smoke test

为了避免直接跑完整 15000 steps，可以先跑极短 smoke test。

建议先用当前项目已有的 no-AMASS 辅助脚本，避免没有 AMASS 时动画数据加载报错：

```bash
cd /workspace/ml-hugs
conda activate hugs
python scripts/run_neuman_human_scene_noamass.py \
  --seq lab \
  --cfg-file cfg_files/release/neuman/hugs_human_scene.yaml \
  --quick \
  --quick-steps 20 \
  --exp-name server_smoke_lab \
  wandb=false
```

如果脚本参数和当前版本不一致，可退回直接运行 `main.py`：

```bash
python main.py \
  --cfg_file cfg_files/release/neuman/hugs_human_scene.yaml \
  dataset.seq=lab \
  exp_name=server_smoke_lab \
  train.num_steps=20 \
  train.val_interval=20 \
  train.save_ckpt_interval=20 \
  train.anim_interval=100000 \
  wandb=false
```

完成后检查：

```bash
find output -maxdepth 5 -type f -name 'human_final.pth' -o -name 'scene_final.pth'
```

## 12. 当前私有仓库中的实验配置说明

当前代码仓库包含我们新增的 Anchor Attention、SuGaR、Global-aware Voxelized ADC 等实验配置和脚本。

其中一些配置是从已有训练 checkpoint 继续训练，例如配置中出现类似：

```text
human.ckpt: output/human_scene/.../ckpt/human_final.pth
scene.ckpt: output/human_scene/.../ckpt/scene_final.pth
```

这些路径引用的是当前服务器历史训练产物，本次不拷贝 `output/` 时，在公司服务器上会不存在。

因此公司服务器初始阶段建议先跑：

- 官方 pretrained evaluation
- 官方 baseline 从零训练
- 不依赖历史 `output/human_scene/.../ckpt/*.pth` 的实验配置

如果要继续某个依赖历史 checkpoint 的实验，有两种选择：

1. 在公司服务器上先复现实验前置训练，生成对应 checkpoint。
2. 只传对应那一次实验的 `ckpt/human_final.pth` 和 `ckpt/scene_final.pth`，不要传整个 125G `output/`。

## 14. 常见问题

### 14.1 `ModuleNotFoundError: diff_gaussian_rasterization`

重新编译子模块：

```bash
cd /workspace/ml-hugs
conda activate hugs
pip install submodules/diff-gaussian-rasterization
pip install submodules/simple-knn
```

### 14.2 `torch.cuda.is_available()` 是 `False`

检查：

```bash
nvidia-smi
python -c "import torch; print(torch.__version__, torch.version.cuda, torch.cuda.is_available())"
```

如果驱动或 CUDA wheel 不匹配，需要让平台管理员确认 NVIDIA driver 支持 CUDA 11.7 运行时。

### 14.3 缺少 SMPL 文件

错误通常会指向 `data/smpl`。确认：

```bash
ls data/smpl/SMPL_NEUTRAL.pkl
ls data/smpl/smpl_uv.obj
```

### 14.4 官方下载慢或断开

可重复执行：

```bash
wget -c https://docs-assets.developer.apple.com/ml-research/models/hugs/neuman_data.zip
wget -c https://docs-assets.developer.apple.com/ml-research/models/hugs/hugs_pretrained_models.zip
```

然后手动解压：

```bash
unzip -qq neuman_data.zip
unzip -qq hugs_pretrained_models.zip
```

### 14.5 没有 AMASS

AMASS 只用于 novel animation rendering。官方 NeuMan 训练和 pretrained evaluation 不应强依赖 AMASS。如果遇到动画数据加载问题，优先使用 `scripts/run_neuman_human_scene_noamass.py` 做训练入口，或把 `train.anim_interval` 设置成很大的数。

## 15. 最小可执行清单

公司服务器 coding agent 可以按以下顺序执行：

```bash
# 1. clone code
cd /workspace
git clone git@github.com:OIIAIIOOIIAII/ml-hugs-work.git ml-hugs
cd /workspace/ml-hugs
git submodule update --init --recursive

# 2. create env

conda activate hugs

# 3. download official data and pretrained weights
bash scripts/prepare_data_models.sh

# 4. place SMPL manually
mkdir -p data/smpl
# Put SMPL_NEUTRAL.pkl and smpl_uv.obj into data/smpl/

# 5. verify environment
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
python -c "import diff_gaussian_rasterization; print('diff gaussian ok')"
python -c "import simple_knn; print('simple knn ok')"

# 6. verify official pretrained evaluation
python scripts/evaluate.py -o output/pretrained_models/lab

# 7. smoke train
python scripts/run_neuman_human_scene_noamass.py \
  --seq lab \
  --cfg-file cfg_files/release/neuman/hugs_human_scene.yaml \
  --quick \
  --quick-steps 20 \
  --exp-name server_smoke_lab \
  wandb=false
```

如果以上步骤全部通过，公司服务器上的项目就已经具备运行官方 HUGS 数据、官方 pretrained weights、以及当前私有代码分支的基础能力。
